O desenvolvimento foi transferido de ambiente no meio da v0.5. Este documento evita que código parcialmente implementado seja confundido com versão concluída.

## Intenção da v0.5

Fechar a cadeia de campo real:

`Talhão → Ordem de coleta → Grid/pontos → GPS → Coleta → Amostra → Resultado laboratorial`

Adiciona metadados de estratégia de amostragem, sequência, posição observada, precisão GPS, payload de origem, índices e `updated_at` para ordens de coleta.

`src/domain/field-operations.ts`

- CSV com delimitador `;`, `,` ou TAB;
- coordenadas com decimal brasileiro;
- GeoJSON FeatureCollection de Point;
- aliases de cabeçalho;
- bloqueio de código/coordenada duplicados;
- validação geográfica básica.

### Operações persistentes

`src/lib/repositories/collections.ts`

- listar ordens;
- criar ordem;
- gerar pontos GRID via PostGIS;
- importar pontos CSV/GeoJSON;
- conferir ponto dentro do talhão;
- registrar posição observada do GPS;
- medir distância para o ponto planejado;
- atualizar progresso/estado;
- auditoria.
