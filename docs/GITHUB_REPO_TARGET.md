## Importante

O conector GitHub disponível no ChatGPT consegue ler e escrever em repositórios existentes, mas nesta sessão não expõe a ação de criar um repositório novo. Portanto, o repositório precisa existir no GitHub uma única vez antes do primeiro `git push`.

Depois que o repositório vazio existir, basta executar:

```bash
git push -u origin main
```

Não inicialize o repositório remoto com README, .gitignore ou licença, para evitar conflito desnecessário no primeiro push.
